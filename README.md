# Pump Station Automation

Проект автоматизированного управления насосной станцией, разработанный в CODESYS.

## Описание

Проект предназначен для управления двумя насосами. Предусмотрены ручной и автоматический режимы работы, контроль давления и уровня воды, а также защитные блокировки и аварийная сигнализация.

## Функциональные возможности

- Ручное управление насосами.
- Автоматическое управление в зависимости от давления.
- Контроль уровня воды.
- Защита от сухого хода.
- Задержка включения второго насоса.
- Аварийная сигнализация.
- Блокировка одновременного включения несовместимых режимов.

## Логика работы

### Ручной режим

В ручном режиме оператор управляет насосами с помощью команд запуска и остановки. Работа насосов ограничивается сигналами защит и блокировок.

### Автоматический режим

В автоматическом режиме контролируется давление в системе. При снижении давления формируется команда на включение насоса. Если производительности первого насоса недостаточно, второй насос включается после заданной задержки.

### Защита и аварийная сигнализация

В проекте предусмотрены:

- контроль минимального уровня воды;
- защита от сухого хода;
- блокировка работы при срабатывании защит;
- сигналы аварии по уровню воды и сухому ходу;
- общий сигнал аварии.

## Основные переменные

| Переменная | Назначение |
|---|---|
| `START_02` | Команда запуска второго насоса |
| `STOP_02` | Команда остановки второго насоса |
| `PRESSURE_LOW` | Сигнал низкого давления |
| `PRESSURE_HIGH` | Сигнал высокого давления |
| `AUTO_MODE` | Выбор автоматического режима |
| `MANUAL_MODE` | Выбор ручного режима |
| `LEVEL_LOW` | Сигнал низкого уровня воды |
| `LEVEL_OK` | Сигнал допустимого уровня воды |
| `DRY_RUN` | Сигнал сухого хода |
| `SAFETY_OK` | Состояние защит |
| `LEVEL_LOW_ALARM` | Авария низкого уровня |
| `DRY_RUN_ALARM` | Авария сухого хода |
| `GENERAL_ALARM` | Общий сигнал аварии |
| `T_PUMP2_DELAY` | Таймер задержки запуска второго насоса |

## Используемые технологии

- CODESYS V3.5
- Язык программирования LD (Ladder Diagram)
- CODESYS Control Win V3
- PLCopen XML

## Запуск проекта

1. Откройте CODESYS.
2. Импортируйте файл проекта в формате PLCopen XML.
3. Проверьте конфигурацию устройства и назначение входов и выходов.
4. Выберите целевую среду выполнения.
5. Выполните сборку проекта.
6. Запустите проект в режиме симуляции или на подключенном контроллере.

Для работы с физическим оборудованием необходимо предварительно настроить адресацию и подключение входов и выходов.

## Структура проекта

Основная логика управления расположена в программе `PLC_PRG`.

## Назначение проекта

Проект может использоваться для изучения принципов автоматизации насосных установок, разработки логики управления ПЛК и проверки защитных алгоритмов в среде CODESYS.
